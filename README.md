# 情绪记录（MoodLog）

> 点一下记时间 → 选一下感受 → 给医生看的东西自动长出来。
> **数据只存在你手机浏览器里，不上传、不联网。**

## 它是什么

一个单页小应用（PWA）。手机上「添加到主屏幕」后，和一个 App 没区别：

1. 打开 → 中间一个巨大的 **「现在」** 按钮（上面实时显示当前时间）
2. 点一下 → **立刻记下这个时刻**
3. 弹出第二步：选感觉（焦虑、抑郁/低落、失眠、心悸、烦躁…）→ 拉强度 1~10 → 可选写一句备注 → 保存
4. 三个页面：**记录 / 时间轴 / 统计**
5. 底栏 **「给医生的报告」** → 自动生成近 30 天汇总（次数、天数、平均强度、最常见感觉、逐条明细），可直接打印或截图发给医生

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 整个应用（HTML+CSS+JS 全在一个文件里） |
| `sw.js` | Service Worker，让应用**离线也能打开** |
| `manifest.webmanifest` | 让它能"添加到主屏幕"，全屏运行 |
| `icon-192.png` / `icon-512.png` | 图标 |

## 放到 GitHub 上（不用装 Git，全在网页上点）

1. 打开 GitHub，右上角 **＋ → New repository**
   - Repository name：`mood`（或你喜欢的名字）
   - 选 **Public**
   - 勾选 **Add a README file** → Create
2. 进入仓库 → **Add file → Upload files**
   - 把 `index.html`、`sw.js`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png` 五个文件一起拖进去
   - 底下点 **Commit changes**
3. 仓库页 → **Settings → Pages**
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/ (root)** → **Save**
4. 等 1~2 分钟，页面顶部会出现：
   ```
   Your site is live at https://你的用户名.github.io/mood/
   ```
5. 手机浏览器打开这个地址 → 菜单里选 **「添加到主屏幕」**
6. 从桌面图标打开 → 全屏、离线可用

> 网址记得收藏；换手机时用「备份」导出 JSON，新手机上用「恢复」导入。

## 如果 GitHub 打不开

两个替代：

**① Gitee Pages（国内快）**
把同样五个文件建一个仓库，服务 → Gitee Pages → 部署，得到 `https://用户名.gitee.io/mood/`。
（Gitee Pages 需要实名认证，服务有时会暂停，以平台说明为准。）

**② 电脑上先预览**
双击 `preview.bat`，浏览器打开 `http://127.0.0.1:8080`。
这个只适合自己试功能，**手机用不了**（除非再把端口映射出去）。

## 数据安全

- 所有记录存在浏览器 **localStorage** 里，键名 `moodlog.v1`
- **不上传任何服务器**，断网也能用
- 风险：**清除浏览器数据 / 换浏览器 / 卸载** 会丢
- 所以：每周点一次底栏「备份」，把 JSON 存到微信收藏或网盘
- 别把导出的 JSON 传到公开仓库（里面有你的备注）

## 给医生怎么说

> "这是我近一个月自己记的情绪记录，包括时间、当时的感觉和强度。
> 我知道这不是量表，但可以看看我在什么时段、什么情况下最明显。"

## 后续可以加的（等你用一阵再说）

- 诱因标签（工作/人际/身体不适/睡眠）
- 用药记录（吃了什么、几点、反应）
- 周期关联（女性生理周期）
- 一周提醒（"这周还没记录"）
- 导出 PDF 而不是网页打印

## 边界

本工具用于个人自我观察与就诊沟通，**不是医疗器械，不提供诊断或治疗建议**。
